TECNOLOGIA
----------
- Next.js 16 (App Router, site 100% estático)
- React 19
- Tailwind CSS 4 (tokens customizados no globals.css)
- TypeScript
- Fonte: Poppins (Google Fonts, via next/font, self-hosted)
- Sem bibliotecas externas de UI ou animação (tudo CSS puro)

COMANDOS
--------
- npm run dev    -> roda o servidor de desenvolvimento
- npm run build  -> build de produção
- npm run start  -> serve o build
- npm run lint   -> checagem de código

-----------------------------------------------------
TIPOGRAFIA
-----------------------------------------------------
FONTE: Poppins (pesos carregados: 400, 700 e 900)

- Títulos (h1, h2, números grandes) .... Poppins Black  (font-black)
- Subtítulos e frases de destaque ...... Poppins Bold   (font-bold)
- Corpo de texto e descrições .......... Poppins Regular (padrão)

Aplicada automaticamente em todo o site via --font-sans
e --font-poppins (app/layout.tsx + app/globals.css).

-----------------------------------------------------
ESTILO VISUAL / IDENTIDADE
-----------------------------------------------------
- Estilo jovem com pegada de GRAFITE: respingos de tinta
  (SpraySplat), marcações de spray atrás de palavras
  (SpraySwipe), faixas de tinta entre seções (PaintDivider)
- Botões com borda "tremida" pintada a mão, rotação de
  adesivo, sombra sólida verde, gota de tinta e brilho
  no hover (classes .btn-paint-* em app/globals.css)
- Animações: brilhos flutuando, anéis orbitais, letreiro
  infinito (marquee), revelação ao rolar (Reveal) e
  contagem de números. Todas respeitam prefers-reduced-motion
- GIFs de pinguins dançando nas laterais das seções

-----------------------------------------------------
COMO EDITAR COISAS COMUNS
-----------------------------------------------------
- Trocar um texto de seção: abra o arquivo da seção em
  components/sections/ e edite o array/parágrafos no topo
- Trocar cores ou fonte: app/globals.css
- Ordem das seções: app/page.tsx
- Links do menu: components/layout/header.tsx e footer.tsx
